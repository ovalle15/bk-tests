# Buildkite queue routing

The NASA dynamic pipeline assigns every generated job to a queue through
`scripts/queue_router.py`. The shared policy is in
`.buildkite/queue-routing.json`.

## Change where jobs run

Each workload selects a queue type:

```json
"unit": {
  "queue_type": "self_hosted"
}
```

The queue type then selects the actual Buildkite queue key:

```json
"self_hosted": {
  "queue": "kube"
}
```

To move a workload to Buildkite hosted agents, first put the organization's
real hosted queue key in `queue_types.hosted.queue`, then change that
workload's `queue_type` to `hosted`. Queue keys must already exist in the same
Buildkite cluster as the pipeline.

Use a workload-level `queue` property only when one workload needs a more
specific queue than the default for its type:

```json
"e2e": {
  "queue_type": "self_hosted",
  "queue": "eks"
}
```

The `deploy` workload controls the queue passed to the triggered `ao-deploy`
build. That pipeline's bootstrap and uploaded deployment steps both reference
`${QUEUE}`, so changing the `deploy` route changes the queue end to end.

## Check routing before committing

```bash
python3 scripts/queue_router.py validate
python3 scripts/queue_router.py list
python3 scripts/queue_router.py resolve integration
```

Preview the complete dynamic pipeline:

```bash
BUILDKITE_BRANCH=main python3 scripts/generate_pipeline.py
```

## Temporary overrides

Overrides let engineers reroute jobs for one Buildkite build without editing
the committed policy:

```bash
# All hosted workloads
BUILDKITE_QUEUE_HOSTED=my-hosted-queue \
  python3 scripts/queue_router.py list

# All self-hosted workloads
BUILDKITE_QUEUE_SELF_HOSTED=eks \
  python3 scripts/queue_router.py list

# One workload (highest priority)
BUILDKITE_QUEUE_WORKLOAD_E2E=eks \
  python3 scripts/queue_router.py resolve e2e
```

Set these variables in the Buildkite build environment when using an override.
Do not use agent hooks for permanent routing policy, because the job must be
assigned to a queue before an agent can run those hooks.

The initial job that runs `pipeline.dynamic.yaml` is not generated by Python.
Configure that bootstrap job's queue separately in the Buildkite pipeline
steps editor. All jobs produced by `generate_pipeline.py` use this router.
